# Playwright 2x

A repository for learning, practicing, and experimenting with JavaScript and Playwright.

## Getting Started

### Prerequisites

To run the scripts in this repository, you need to have [Node.js](https://nodejs.org/) installed.

### Installation

Clone the repository:
```bash
git clone https://github.com/Kishores548/playwright_2x.git
cd playwright_2x
```

Install Playwright (when Playwright dependencies are added):
```bash
npm install @playwright/test
npx playwright install
```

## Running Scripts

To run the standard JavaScript console script:
```bash
node console.js
```

## Repository Structure

- `console.js`: A simple JavaScript script demonstrating console output.
